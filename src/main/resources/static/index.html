The craft

Built like a workshop, not a chat app.

01

Operational transform

Concurrent edits are rebased pairwise the moment they land. Your text never shifts under someone else's cursor, and no keystroke is ever thrown away — every op is transformed, not rejected.

02

Rooms, not repos

Pick a room code and share the link. There is no signup, no project setup, no import ceremony. The document is simply there, warm, the second you arrive — and everyone you send the link to.

03

One ordered authority

A single server orders every operation and echoes it back as the acknowledgement. Clients keep one edit in flight, so convergence is a property of the protocol — not of luck or timers.

Questions

Asked at the door.

How do I invite someone?

Copy the room link from the studio header. Anyone who opens it lands in the same room, on the same document, in the same second — presence chips show every cursor the moment they arrive.

What if we type at the same caret?

The server transforms each operation against everything that landed before it. Both edits survive, repositioned so the document stays exactly what both authors meant — no locks, no last-write-wins roulette.

Is my code stored anywhere?

Rooms live in the server's memory while the process runs. Nothing is written to disk, no accounts are kept, and a restart starts every room fresh at an empty page.

Which languages are highlighted?

Java tokens today — keywords, strings, comments and numbers. The highlighter is a single regex table in the studio, built to be extended one line at a time.

What happens if the server is down?

The studio drops into solo mode: you keep typing against a local page, and your whole buffer is pushed as one operation the moment the socket comes back.
